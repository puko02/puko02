## 💡 Projetos em destaque

### 🍔 Quick-Bite
Projeto de desenvolvimento de uma plataforma de delivery de alimentos, com navegação por produtos, lojas parceiras e carrinho de compras.

**Tecnologias:** HTML, CSS e JavaScript.

🔗 [Acessar repositório](https://github.com/puko02/Quick-Bite-)

### ⚖️ Site-Advocacia
Projeto de desenvolvimento de um site para escritório de advocacia, com proposta de funcionalidades para agendamento de consultas e gerenciamento de atendimento.

**Tecnologias:** HTML, CSS e JavaScript.

🔗 [Acessar repositório](https://github.com/puko02/Site-Advocacia)

### 📋 FastTask
Gerenciador de tarefas online com integração de API e autenticação por e-mail. Organiza tarefas através de quadros, colunas e tarefas individuais.

**Tecnologia principal:** JavaScript.

🔗 [Acessar repositório](https://github.com/puko02/FastTask)

### 🚗 AutoPrime
Projeto de uma concessionária fictícia de veículos de luxo, com funcionalidades voltadas ao gerenciamento de usuários, estoque e vendas.

🔗 [Acessar repositório](https://github.com/puko02/AutoPrime)
